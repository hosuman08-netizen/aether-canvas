# Aether Canvas — 음성 아트 레코더

목소리를 부드러운 스푸마토 빛의 파형으로 그려주는 음성 녹음 아트 앱.
이어폰(또는 마이크)으로 말하면 실시간 비주얼라이저가 반응하고,
녹음을 노트북에 저장해 나중에 다시 들으며 관찰할 수 있습니다.

순수 창작용 도구입니다. 도박 요소나 결제 요소가 없습니다.

## 주요 기능
- 🎙 실시간 녹음 + 스푸마토 파형 비주얼라이저 (실제 Web Audio 분석 기반)
- 📓 노트북: 녹음과 감상 메모를 저장
- 🔁 다시 듣기: 저장한 녹음을 다시 재생하며 파형을 감상
- ⬇ 파일 저장: 녹음을 기기에 .webm으로 내보내기

## 시작하기
`index.html`을 브라우저에서 열거나 로컬 서버로 서빙하세요.
마이크 권한을 허용하면 녹음이 시작됩니다.

- 스페이스바: 녹음 시작/정지
- N 키: 노트북 열기

## 구조
- `index.html` — 화면 마크업
- `style.css` — 스타일 (골든비율 레이아웃, 8px 그리드)
- `script.js` — 녹음/재생/시각화/노트북 로직
- `golden-detail.js` — 골든비율 디테일 액센트 렌더

## 저장 방식
- 세션 메타데이터: localStorage
- 오디오 클립: IndexedDB (새로고침 후에도 다시 듣기 가능)

모든 데이터는 사용자 기기에만 저장되며 외부로 전송되지 않습니다.
